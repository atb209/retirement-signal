Behind the page

How this page updates

  1. Every weekday morning the same automated job that updates the signal reruns every check on this page.
  2. Most checks use FRED, the Federal Reserve Bank of St. Louis's free data service. Two also use other public sources: a fund company's daily list of S&P 500 holdings, and Robert Shiller's long-run earnings data.
  3. If a source can't be reached, that one check keeps its last reading and is marked "not updated". Every other check still runs, and the signal itself is never affected.
  4. The return estimate is computed here. It divides today's S&P 500 price by a stored 10-year earnings figure, which is refreshed whenever its source can be reached. The card shows when that figure was last refreshed.
  5. The historical tests are rerun on every update and compared with their expected results, so a change in the data or the code shows up here.

Data: FRED, Federal Reserve Bank of St. Louis; State Street or iShares fund holdings; multpl.com (Robert Shiller's data).
